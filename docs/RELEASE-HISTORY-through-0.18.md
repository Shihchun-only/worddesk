0.18.0 · Windows 桌面软件。查词窗口左侧是 Merriam-Webster，右侧是剑桥英语简体中文词典。

## 打开软件

打开 `WordDesk-0.18.0-win32-x64` 文件夹，双击 `WordDesk.exe`。也可以使用项目目录中的“启动查词软件.cmd”。请保留同文件夹的所有配套文件，不要只移动 exe。无需安装 Node.js、Python 或数据库。

- 复习页的音标按钮位于“查看完整词条”和“删除单词”左侧。复习释义和左侧列表均不再显示 MW / Cam 来源标签，原词库保留来源切换。

- 考试结束按单词统计首次答对、答错过、看过答案、跳过、使用提示；各类可重叠。首次答对指未用提示且首次输入正确。可以重练未掌握题；提前结束时剩余题计为跳过。
- 进度和成绩仅保留当前软件会话，切换页面可继续，关闭软件后清空；不修改原词库、不保存长期成绩。

## 使用步骤

1. 输入单词或短语，按回车。两侧均可继续浏览，拖动中间分隔条调整宽度。
2. 网页显示词条后，点击“收藏进”，选择一个或多个分组；也可在弹窗中搜索或新建分组。“就近收藏”使用上一次成功收藏的分组组合，关闭软件后仍记住。上方按钮收藏两部词典，左右窗口的按钮只收藏对应词典。遇到网页验证，请先在该网页中完成验证。两边不同词头分别保存，不会强行合并。
3. 在“我的词库”点击“选择释义”。首次默认空选，再次进入会载入已保存的释义与例句选择。选释义不会自动选择例句。选择中可切换 MW / Cam，点击“保存选择”统一保存两边的选择。“清空当前词典”只清空当前来源的草稿；取消则放弃两边草稿、保留原选择。离开页面、切换单词或关闭软件前，改动过的选择会提示处理。个人笔记离开输入框后保存，释义编辑需在弹窗中点击“保存”。
4. “复习词库”共用相同的单词和分组，同时展示 MW / Cam 已选的词性与释义。点击单词旁弯月显示音标；双选优先 MW，单选使用对应词典，MW 可播放已下载录音。剑桥仅英文选择不会显示或导出该条中文释义，中英选择同时保留两种语言。例句、笔记和 MW 中文辅助翻译默认收起。未选择的单词显示“去选择释义”；“查看完整词条”可返回完整阅读。
5. 点击单词旁的 MW / Cam 切换阅读内容，不改变复习或导出内容。
6. MW 每条释义末尾的“译”按钮只翻译该条完整释义，点击不会改变选择。已有译文可展开、收起和离线查看；需要时在译文下点击“重新翻译”。不再提供例句自动翻译，词典自带和以前保存的例句译文保留。翻译使用 MyMemory 在线服务，免费额度用尽或网络失败时，可稍后重试。
7. “导出复习表”选择全部、某个分组或手动勾选的单词，选择列、用箭头调整列顺序，再选收藏时间、字母或随机排序，导出 `.xlsx`。
8. 用 Excel 或 WPS 调整打印样式。软件生成文件本身不需要安装 Excel。
9. 两个词库均可单独删除或勾选多个单词批量删除，操作同步至另一词库及所有分组。删除先进入回收站，7 天内可完整恢复。只想调整分类时，选中分组和单词后使用“移出当前分组”。回收站中的“永久删除”会立即清理该记录及未被其他记录使用的音频和截图。

## 旧词条升级

0.3.0 不会直接改写旧词条。打开旧词条后，点击“重新提取此词典”，联网更新该来源的释义分组和音标；两部词典分别更新。无法可靠对应的旧释义、个人修改和选择保留在“更新待确认”，请对照后重新选择。

MW 的 also、especially 等同一义项内的补充内容现在属于同一个选择框；原文独立编号的子义项仍单独选择。see also、compare 等参见内容不作为释义。

## 收藏与更新

- 同一单词在多个分组中共用记录。再次收藏直接更新该词典原始内容，保留笔记及能对应的个人编辑、释义与例句选择。
- 旧释义无法与新版匹配时，显示“更新待确认”。旧编辑会保留供对照，不会混入新释义导出。核对后可移入历史记录。
- 两部词典使用各自原始标音，并显示为 `/…/`。不同词形、派生词及特定用法说明分别归属；also、or 等说明放在斜线外。MW 标音不转换为剑桥 IPA。
- 保存当前页面已经包含的词条释义、例句、词形、标签、短语等；页面上只有链接的短语保存名称，不自动追踪抓取链接后的所有页面。可以点击短语再单独收藏。
- MW 页面中的主词典、儿童词典、医学和法律等释义均保存，阅读区隐藏这些版本名称。可在导出前取消不需要的释义。
- 新收藏不再保存网页截图。旧截图在主动清理前保留于本地，且仍包含在完整备份中。
- MW 音频下载失败会提示，并提供重试按钮；剑桥录音不再下载。
- 网页结构可能变化。重要词条可重新查词对照官网核查，出现遗漏请反馈具体单词及来源。

## 存储与备份

“存储与备份”显示当前词库的实际位置。默认在 Windows 用户应用数据目录的 WordDesk 目录内，独立于程序文件夹。

更换位置会把词库复制到新建文件夹，原目录保留。完整 ZIP 备份包含词条、回收站、音频、截图、分组和个人编辑。恢复时新建文件夹并切换到恢复的词库，不覆盖当前词库。恢复支持解压后总量不超过 5GB 的备份。

浏览器登录状态和 Cookie 不属于词库备份。

## 开发

源代码位于 `src/`，测试位于 `test/`。使用 Node.js 24 与 pnpm 安装依赖；若 Electron 二进制未下载，运行 `node node_modules/electron/install.js`。

- 启动：`node node_modules/electron/cli.js .`
- 核心测试：`node --test test/*.test.cjs`
- 真实网页验收：`node scripts/smoke.cjs`
- 打包便携目录：`node scripts/package.cjs`

0.3.0 界面验收：`node scripts/v3-ui-test.cjs`。词典结构验收：`node scripts/parser-v3-test.cjs`（使用本地真实网页样本）。联网更新与备份验收：`node scripts/v3-live-test.cjs`。

0.4.0 界面验收：`node scripts/v4-ui-test.cjs`；0.3.0 界面脚本保留作历史记录，其旧界面选择器不适用于新版。

0.5.0 界面验收：`node scripts/v5-ui-test.cjs`。旧版本界面测试的选择规则与新版不同，仅作为历史记录保留。

真实网页测试和界面测试使用独立测试词库，避免修改日常词库。

0.6.0 界面验收：`node scripts/v6-ui-test.cjs`，双词典交互回归：`node scripts/v5-ui-test.cjs`。

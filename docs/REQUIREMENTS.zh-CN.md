# WordDesk — 最新产品需求（0.20.0）

本文件是截至 2026-10-03 已确认需求的整合版。历史对话中较早、与本文件冲突的要求已经被后续决定替代。新需求应先说明修改建议，用户确认后再实现；用户明确授权直接修改时可继续。

## 1. 产品定位

Windows 桌面查词、个人词库、PDF 阅读和纸面复习软件。用户使用 Windows 10、小屏幕电脑，重视直观操作与阅读空间。设计简洁，参考 OpenAI 官网的克制风格。无需终端即可使用发行包。数据默认本地保存，可选存储位置，无账号/云同步。

## 2. 双词典查询与收藏

- 一个搜索框，回车同时查询左侧 Merriam-Webster（MW）与右侧剑桥英语简体中文词典；网页内可独立导航。
- 支持同时收藏两部词典和单独收藏。不同词头不能混入同一记录；保留每个来源。
- “收藏进”选择一个或多个现有分组，支持创建分组；“收藏到上次分组”复用上一次成功收藏的分组组合。
- 收藏完整目标词条：全部释义及层级、例句/译文、词性、原始音标、可用词形、短语/习语、使用标签、交叉参见。排除导航和广告；不自动遍历所有短语链接。
- 同一单词多个分组共用一份数据。重复收藏直接更新，保留个人修改、笔记、选择；无法对应的旧释义保留为待核对/历史，不能静默删除。
- 新收藏的释义、例句默认全不选；已有保存选择再次进入编辑时高亮保留。
- 部分失败先保存成功内容，标明缺失及重试入口；网站验证由用户在网页完成。
- 收藏显示阶段（提取、录音下载数量、保存）。离开查询页面、切换工作标签或发起新查询后，完成不能打断当前操作；即使离开后返回也不自动跳转。完成提示可主动“查看词条 / 重试”。始终停留原查询页时保留自动打开词条行为。
- 两部词典先提取内容再下载录音，避免后续查询污染本次收藏。

## 3. 发音、释义准确性和翻译

- MW 保留 MW 标音，剑桥保留剑桥 IPA，音标以 /.../ 包裹；横向流式排列，空间不够才换行。
- 不同词形和特定用法说明按词典原文保留，不能把形态、注释或孤立的 or 当作独立音标。
- 剑桥用 UK / US，去除相同词形、地区、音标与说明的重复项目，真正不同变体必须保留。
- 复习、考试、导出统一只取 MW 音标，包括只选了剑桥释义的情况。缺少 MW 就提示缺失，不能回退剑桥。
- 仅下载 MW 录音并支持离线播放。剑桥官网可在线播放，不再下载；可清理旧剑桥音频。
- 不再保存网页截图；已有旧截图只通过显式清理操作移除。
- 释义按词典原来的完整条目选择。also / especially 等子行与所属释义保持在一个选项中；不能把 see also / compare 交叉参见当释义。
- 保留原始编号（例如 2a），不重新顺序编号；剑桥没有原始编号时不制造编号。
- 不展示“主词典/儿童词典”等多余来源区块标签；必要词义/短语上下文仍保留。
- MW 按需翻译释义：先看英文，点按钮才请求在线服务，免费优先，缓存译文并允许编辑。翻译按钮位于释义末尾，编辑按钮相邻。不翻译例句。
- “编辑释义 / 我的翻译”不破坏原文；取消编辑不保存；已存自动译文和个人译文可分别查看/导出。

## 4. 我的词库与复习词库

- 我的词库按词典结构展示完整词条；词头旁放 MW / Cam 标签，方便切换。详情不重复展示所属分组。
- “选择释义”在顶部常驻操作栏。选择时可自由切换 MW / Cam，草稿不丢失。保存两部来源的选择，复习不能只保留最后一部。
- 选择以完整释义为单位，可选择例句。剑桥英文与中文分别点击：英文只选英文；中文同时选择中英文。语言选择各条独立保存。
- 全选、清空当前词典、取消、保存、重新查词、删除等操作栏在长内容滚动时常驻；清空只影响当前来源。
- 复习与我的词库共享单词和分组，只展示已保存选择。两来源共同参与，默认不显示词典来源标签。
- 复习音标默认隐藏，显示音标/隐藏音标文字按钮切换，位于“查看完整词条 / 删除单词”左侧。
- 可单个/批量删除；任意视图删除同步整个词库。分组可删除，但不能连带删除单词；支持只从某分组移除。
- 两部词典都无已保存释义时，列表高亮并显示“未选释义”。任意一条已选即取消标记；未保存草稿不影响判断。
- “仅未选释义”开关带数量，与当前分组、搜索组合使用；全部分组表示全库。我的/复习视图分别记住状态，工作模式复用同一设置。
- 保存后符合条件的词从筛选列表移除，但右侧保留当前词条供确认。

## 5. 考试

- 使用复习中保存的释义，单词替换为输入框。Enter 检查，下一次 Enter 进入下一题。正确判定忽略大小写、首尾和连续空格、直弯引号差异；词形必须正确。支持 IME 输入，不在组合输入时误提交。
- 词性隐藏，释义编号保留；不显示来源。
- 答题区默认下方，可在设置切换上方；输入、检查、下一题、显示答案、跳过、结束等一起移动，进度顶部，释义独立滚动。切换保留输入与进度。
- 支持范围/顺序、跳过、显示答案、结束、本次统计与重练未掌握题。成绩仅本次会话，不做提醒或长期掌握状态。
- 只有题目原词是正确答案，相关词形不算答对。
- 默认遮盖答案及常见相关词形：通用形态规则、常见词族、不规则变化表共同处理，完整词匹配，统一 ______，不按任意字母相似度遮盖。
- 适用于释义、例句、译文、笔记和音标旁说明。原文数据不变。手动“考试遮盖词”补充词或短语，逗号/换行分隔，保存后重启仍保留。
- 设置可关闭遮盖，显示原文但继续隐藏词性；不删除自定义遮盖词。关闭时当前未完成和后续显示的题记为使用提示，重新开启不撤销；已完成结果不受影响。
- 词族规则是启发式，不宣称穷尽英语形态，可能漏判/误判。

## 6. 工作模式与 PDF

- 浏览器式标签栏，固定“双词查询”和“我的词库”，PDF 可多标签打开/关闭。我的词库内切换完整/复习，不复制数据。
- 可选文本 PDF 复制后自动跳到查询；可关闭自动查询，另有显式复制并查词。不含 OCR。
- 记录文件、阅读页码、缩放、滚动和实际复制查词位置的高亮。不全文高亮所有相同词。
- 支持阅读历史继续，文件移动时重新定位相同内容；重启不自动恢复所有标签。
- 点击高亮展示当前复习释义小窗，改动后重新打开显示最新内容；未收藏/未选时明确提示。
- 小窗按词性分组，相同词性只显示一次（跨 MW/Cam）；transitive / intransitive 分开，保留原编号、完整多行释义、必要上下文和已选中文。内容独立滚动，关闭等操作常驻。
- 小窗可打开复习词条、去选释义、查词、取消本处高亮；音标仍只用 MW。
- 标签切换保留查询、词库筛选/滚动、草稿和 PDF 状态。词条切换、关闭程序或覆盖更新前保护未保存草稿。
- 工作模式收藏后自动进入选择释义：设置开关默认开启，新词不预选，重复收藏保留选择；关闭仅打开完整词条。
- 选择栏“取消”和“保存选择”间新增“保存并回到 PDF”；先保存两来源成功再返回。失败保留草稿并留在原处。
- 普通词条栏“选择释义”左侧有“回到 PDF”，不改选择。优先本次查词来源，手动查询返回最近阅读 PDF，恢复原阅读位置；无目标或源标签关闭时置灰，不能跳到其他文件。
- 支持专注阅读、全屏/F11、Esc 退出；小屏幕可最大化阅读空间。

## 7. 导出 Excel

- 范围：全库、指定分组、手选；顺序：收藏时间、字母、随机。列自由勾选/排序，记住上次导出选项。
- 默认 Word / Part of Speech / Definition（单词/词性/释义）三列，比例约 20/15/65。默认合并释义按 MW 英文和剑桥已保存的英文/双语选择输出；辅助译文可另选列。
- 不加来源标签，保留词典原编号、完整释义和必要上下文。MW 音标是唯一导出发音来源。
- A4 竖向、12mm 边距、重复表头、页码、细灰线；单词12pt加粗、正文11pt、英文Calibri/中文微软雅黑，左上对齐并换行。一页宽、不限纵向页数。
- 长词条优先按整条释义续行，单条极长时仍应继续、不截断；续行标记。多列时提示拥挤，提供一键恢复三列布局。
- 不添加复杂排版模板编辑器，用户可在 Excel 再调整。

## 8. 设置、存储与隐私

- 浅色/深色；词条字号14–24px滑杆默认18，词库、复习、考试及小窗联动，官网/PDF缩放独立。
- 简体中文/English，默认中文，即时切换并记住；覆盖应用导航、按钮、提示、对话框、进度、考试、PDF工具栏和新导出列标题。
- 词典原文、中文释义、个人翻译、笔记、分组名称和 PDF 内容不能随界面语言被翻译。
- 切语言保留当前词、草稿、考试输入/进度和PDF位置；可以带着草稿进入设置并返回原页。
- 删除进入回收站，保留7天，可恢复/主动永久删除；关机期间过期的内容下次启动清理。
- 本地位置可迁移复制，原目录保留；完整备份恢复包含词条、音频、分组、笔记、选择、PDF历史/高亮、尚未清理旧截图，不包含 PDF 原文件。恢复到新目录，不覆盖原库。

## 9. 不得恢复的旧行为

不要重新添加网页截图、剑桥音频下载、例句自动翻译、复习/考试/导出回退剑桥音标、只保存最后来源选择、默认全选新释义、收藏后台完成强制跳转、词性在考试显示、界面语言翻译用户学习资料。

## 10. 验收与后续优化

需求说明描述目标行为；现有实现的具体限制见 DEVELOPMENT.md。不得仅因文档声称已实现就跳过验证。最新基线0.20.0；TESTING.md是逐版本历史记录，较早版本内容不代表当前需求。任何修改应保持本地用户词库，测试使用隔离目录。

## 11. 0.19.0 已批准的整体优化

- 阅读记录拆分、写入降频并在离开/退出时补存。完整备份仍嵌入 PDF 元数据以兼容旧备份格式。
- 词库与设置原子替换，最近5份有效自动快照及恢复入口；损坏原文件保留。笔记/选择保存失败保留并可重试，不能静默丢弃。
- 收藏文字先保存，MW音频后台、最多2个同时下载，支持跳过与重试，不覆盖新编辑、不跨词库写入。
- PDF逐个搜索命中、前后移动、总数、跨文本片段/换行。
- 上下次提取数量、减少提醒、旧新内容对照，不宣称完整性保证。
- 工作模式称阅读工作台，记住常用入口；文字音标开关、上次分组收藏、次要操作收纳、小屏侧栏不重叠。
- 词条内搜索、词性折叠、跳到已选、双来源草稿预览与统一保存。
- 最新统一界面回归和实际发行包启动验证；历史测试不作为当前验收。

## 12. 0.20.0 版本与更新说明

- 版本号仅在设置 → 关于与更新中查看，不常驻侧栏。直接读取应用实际版本，展示更新日期、本版三项说明，可复制版本信息。
- 已有用户升级后首次启动展示本次更新；关闭按钮及 Esc 都记住已读版本，重新启动不再出现。全新安装不弹升级提示；可随时从设置查看。
- 不请求网络或引入自动升级，提供中英文界面。

# WordDesk 0.20.0

Windows 双词典查词、PDF 阅读、个人词库与纸面复习。

## 源码、需求与软件下载

- [最新版完整需求](docs/REQUIREMENTS.zh-CN.md)
- [开发、测试与打包](docs/DEVELOPMENT.md)
- [验证记录](TESTING.md)

在 [GitHub Actions](https://github.com/Shihchun-only/worddesk/actions) 的 Windows build 成功任务中，下载 WordDesk-windows-x64 构建产物，解压其中的便携 ZIP 后使用。仓库保存源码和需求；个人词库、PDF、录音、浏览器资料、node_modules 和 dist 不纳入版本控制。

## 打开软件

在完整的 `WordDesk-0.20.0-win32-x64` 文件夹内双击 WordDesk.exe，或使用项目目录的“启动查词软件.cmd”。请保留配套文件，不要只移动 EXE。无需安装 Node.js、Python 或数据库。

首次打开进入“阅读工作台”。软件记住最近使用的查词、工作台、词库、复习、考试或导出入口；考试成绩仍只保留当前会话。

## 0.19.0 的变化

- PDF 阅读位置与高亮独立保存；连续滚动合并写入，停止滚动约 750 毫秒后保存，持续滚动最长约 5 秒写入一次。切换标签、关闭标签、离开页面和正常退出会补存。
- 词库与设置采用临时文件替换；词库保存失败不会继续把内存当作已保存状态。笔记和释义选择失败后保留，窗口显示“尚未保存”，可重试。未成功写入的笔记会阻止离开页面和关闭窗口。
- 最近 5 份自动词库快照：启动、首次保存和后续间隔保存建立有效版本，相同内容不重复占用。保存期间的快照间隔约 15 分钟。“存储与备份 → 自动备份与恢复”可恢复到新目录，原目录保留。启动遇到损坏文件时可选择有效自动备份；损坏词库也可从完整 ZIP 备份恢复。
- 收藏先保存两部词典已经提取的文字，MW 录音后台下载，同时最多 2 个任务。可以继续选释义、跳过录音或稍后重试；下载完成不会打断编辑。剑桥录音仍不下载。
- PDF 搜索支持同页多个命中、上一处／下一处、结果数量，以及跨文本片段和换行的短语。当前命中单独突出显示；扫描页仍不支持 OCR。
- 重新收藏显示上次／本次释义数量；减少时提示核查。“对照更新”并排显示旧内容（含个人修改）和新内容。数量不是完整性保证。
- 长词条新增词条内搜索、词性折叠、跳到已选释义。选择时可“预览复习内容”，同时查看两个来源的草稿，继续选择或统一保存。
- 工作模式改称“阅读工作台”；“就近收藏”改称“收藏到上次分组”。主操作突出显示，重新查词和删除放入“更多”。音标改用“显示音标／隐藏音标”文字按钮，小屏侧栏可滚动。

## 阅读与收藏

1. 工作台打开 PDF，选词后 Ctrl+C 查两部词典；可关闭复制自动查词，右键仍可主动复制并查词。
2. 查词结果出现后，使用“收藏进”选择分组，或“收藏到上次分组”。两部词典保留独立来源，不同词头分别保存。
3. 新词默认不选择释义。进入“选择释义”，在 MW／Cam 之间切换选择；两边草稿一起保存。剑桥英文与中文可独立控制，例句单独选择。
4. 用“预览复习内容”检查选择结果。工作台可“保存并回到 PDF”，回到原文件与阅读位置。
5. 收藏后的 MW 录音在后台下载，文字可立即编辑。下载完成后重新打开词条可播放；失败可在完整词条底部“音频下载”重试。

## 词库、复习与考试

- 我的词库、复习词库和工作台中的词库共享同一份数据。仅未选释义筛选按已保存内容计算，草稿不计入。
- MW／Cam 释义均可进入复习，但复习、考试和导出音标始终只使用 MW；缺少 MW 时提示缺失，不回退剑桥。完整词条仍展示各自词典的标音。
- 个人笔记离开输入框后保存；编辑释义需在弹窗点击保存。原始词典释义与个人修改分别保留。
- 重复收藏保留能对应的选择、笔记和个人编辑。无法对应的旧内容放入“更新待确认”，可对照后处理。
- 考试按原单词判题，忽略大小写、重复空格和直弯引号；词形或近义词不算正确。遮盖相关词形是启发式规则，可手动补充遮盖词。
- 删除单词进入回收站，保留 7 天；删除分组仅移除分组，不删除单词。

## 导出与备份

- 导出 Excel 默认单词、词性、释义三列，A4 竖向打印。保留原编号，长释义续行。实际打印仍可在 Excel／WPS 调整。
- 完整 ZIP 备份包含当前词条、回收站、音频、分组、笔记、选择、阅读历史、高亮和未清理的旧截图；不包含 PDF 原文件、浏览器 Cookie 或设置。
- 自动快照只保存词库 JSON。恢复快照时复制当前仍存在的音频文件和当前阅读记录；已经被永久清理的音频不会凭快照重新出现。换电脑或长期存档请使用完整 ZIP 备份。
- 完整备份与自动快照均恢复到新文件夹，原词库保留。移动 PDF 后可在“最近阅读”重新定位原文件。
- 0.19.0 会将阅读记录迁移到独立文件。升级保留原有词库；如需降级，请先导出完整备份，再恢复到单独目录使用旧版。

## 界面与范围

设置支持简体中文／English、浅色／深色和 14–24px 词条字号。界面语言不会翻译词典原文、笔记、个人翻译、分组名或 PDF。

词典网页结构或验证可能影响提取。释义数量与警告帮助检查异常，不能保证网页所有内容都已提取。软件不绕过网站验证。

本版测试目标是 Windows x64。发行包未签名，不含自动升级、云同步、OCR、长期成绩或间隔复习。词族遮盖与 Excel 行高估算仍有适用范围。
